# 交我办场馆空余提醒 AstrBot 插件

该插件读取同一台电脑上的交我办视觉监控状态，并通过 Nalmai 当前使用的 AstrBot/NapCat 给配置的 QQ 私聊发送提醒。使用前必须在插件配置中填写 `recipient_qq`。

## 命令

- `/jwb on`：在当前私聊中增加一个提醒接收方。
- `/jwb off`：关闭额外订阅；固定接收 QQ 不会被该命令关闭。
- `/jwb status`：查看订阅和视觉监控状态。
- `/jwb test`：向固定接收 QQ 测试 AstrBot 主动私聊发送。

订阅命令只能在私聊中使用，插件不会发送到群聊。视觉监控仍然只负责刷新、截图和判断，不会执行预约。

使用时先启动 Nalmai，再运行视觉监控。插件每 5 秒读取一次本机监控状态；视觉监控每 30 秒刷新页面。发送失败会自动重试，成功后不会在同一次持续空余期间重复提醒。
